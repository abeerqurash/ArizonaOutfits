The image optimizer preserves originals and generates WebP copies. Run it again after adding new images. The phone widget on home initializes when its form approaches the viewport; its dropdown and validation library then load normally.

The scores in RESULTS.md were measured in an isolated preview with gzip and caching. Apache hosting uses the previous public/.htaccess rules. If you use php artisan serve, static compression/cache headers may differ because that server ignores .htaccess. This can change scores without changing the page code. Enable production PHP caching on hosting and recheck the real HTTPS domain with PageSpeed Insights.
